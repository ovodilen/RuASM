# RUASM 1.11.5 — происхождение и воспроизводимость

Этот файл описывает проверяемые свойства опубликованного комплекта. Он не заменяет полную историю разработки, квалификационные протоколы или юридическое заключение.

## Состав исходников

Реализация компилятора в этом репозитории состоит из:

- общей логики в `src/core/ruasm-core.asm`;
- платформенного кода Linux в `src/platform/linux/`;
- платформенного кода Windows в `src/platform/windows/`;
- полных сгенерированных translation units в `src/generated/`.

Скрипт `tools/compose-sources.sh` детерминированно формирует оба полных исходника из общего ядра и платформенных частей. Сгенерированные исходники поставляются в репозитории, чтобы сборку можно было воспроизвести без дополнительного генератора исходного кода.

## Проверяемые свойства дистрибутива

Для этой версии зафиксированы контрольные суммы всех включённых файлов в `SHA256SUMS`. Скрипты пересборки используют опубликованные нативные бинарники:

- Linux x86-64 compiler → Linux ELF64; затем побайтовое сравнение с `bin/linux-x86_64/ruasm`.
- Linux x86-64 compiler → Windows PE32+; затем побайтовое сравнение с `bin/windows-x86_64/ruasm.exe`.
- Windows x86-64 compiler → Windows PE32+; этот нативный путь проверяется `scripts/rebuild-windows.ps1`.

Побайтовое совпадение подтверждает воспроизводимость конкретного бинарника из конкретного исходника в конкретном окружении. Оно само по себе не доказывает отсутствие патентных рисков и не заменяет проверку происхождения каждой строки кода.

## Граница утверждений о независимости

Публикуемый GitFlic-комплект намеренно не включает архивы старых версий, историю квалификации или сторонние компиляторы. Поэтому **одного этого репозитория недостаточно для самостоятельного аудита всей эволюции разработки**. Для доказательной истории требуются отдельные подписанные релизы, неизменяемые исходные снимки, журналы переходов, цепочка контрольных сумм и независимая проверка.

В комплект не включены исходники или бинарники сторонних ассемблеров; для сборки опубликованных исходников не требуется внешний ассемблер. Это описание состава данного дистрибутива, а не юридическое заключение о патентной чистоте.
